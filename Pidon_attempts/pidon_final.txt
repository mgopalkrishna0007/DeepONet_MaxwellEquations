PART C — ERROR ANALYSIS: WHAT CAUSED THE ISSUE & FIXES (BULLETS ONLY)
❌ Issue 1 — Channel mismatch after skip concatenation

Cause:

Decoder blocks were initialized assuming fixed channel counts

Skip concatenation doubles channels, but block input channels weren’t updated

Fix:

Explicitly compute:

in_channels = up_channels + skip_channels


Adjust decoder Conv3D blocks accordingly

❌ Issue 2 — Trunk treated like a skip tensor

Cause:

Trunk features were passed into upsampling blocks directly

Conceptually incorrect: trunk ≠ skip

Fix:

Trunk participates only in Hadamard product

Remove trunk from decoder block arguments

❌ Issue 3 — Implicit assumption of spatial alignment

Cause:

No explicit assertion checks before Hadamard product

Fix:
Add runtime checks:

assert branch.shape == trunk.shape


at every Hadamard site

❌ Issue 4 — Architectural entanglement

Cause:

Branch, trunk, and decoder logic interleaved in forward pass

Fix:

Refactor into:

encode_branch()

encode_trunk()

decode()

This prevents silent shape errors.

❌ Issue 5 — Missing explicit normalization

Cause:

Output normalization omitted or applied globally

Fix:

Normalize per-component, per-sample after inference
